# KFUPMYNL — منصة تعليمية

موقع عربي متجاوب، بواجهة HTML/CSS/JavaScript، مناسب للنشر على استضافة صفحات ثابتة مثل GitHub Pages.

## المحتويات
- `index.html`: الموقع والصفحات الداخلية.
- `quizzes/test-1.html`, `test-2.html`, `test-3.html`: ملفات HTML الأصلية المنسوخة دون تعديل.
- `documents/`: ملفات PDF الأصلية (تأسيس المهارات، ميكانيكا البكرات، ملخص الرياضيات).
- `assets/`: صورتا الجدول الدوري والهيكل العظمي كما وصلتا.

## تشغيل محلي
افتح `index.html` في المتصفح. للحصول على أفضل توافق مع عارض PDF والروابط، يُفضّل تشغيل خادم محلي بسيط بدل `file://`.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على المجلدات.
3. من Settings → Pages اختر النشر من الفرع الرئيسي `main` والمجلد `/ (root)` ثم Save.
4. انتظر اكتمال النشر، ثم افتح الرابط الذي تعرضه صفحة Pages واختبره على الجوال والكمبيوتر.

## ملاحظات مهمة
- الموقع لا يحتاج إلى حساب للطلاب ولا يجمع بيانات شخصية.
- اختيار الوضع الفاتح/الداكن يُحفظ محليًا في المتصفح. ملفات الاختبارات الأصلية لم تُعدّل، لذلك لا ندّعي أن تقدم الأسئلة داخل تلك الملفات يُزامن بين الأجهزة أو يُحفظ مركزيًا.
- صفحة «اختبار مجمع» تعرض الاختبارات الأصلية الثلاثة بالتتابع للحفاظ على الإجابات والسلوك الأصلي؛ النتائج تبقى منفصلة داخل كل اختبار ولا توجد درجة إجمالية موحدة.
- ملف تجميعات المهارات لم يكن ضمن الملفات المرفقة وقت الإنشاء، وتم وضع مساحة مؤقتة له.
- تم تضمين ملفات PDF كاملة كما وردت، ولم تُستبدل بمحتوى مولّد. إذا لم يعرض المتصفح ملف PDF داخل الإطار، استخدم زر فتح الملف.
- التذييل يحتوي حرفيًا على: «دعواتكم لـ ينال و نواف ❤️».
